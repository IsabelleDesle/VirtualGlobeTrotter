## ❓ What is Virtual Globetrotter?

**Virtual Globetrotter** is a team project between Atvars Apinis, Isabelle Desle, and Viola Nguyen that provides children with certain limitations the opportunity to explore the world in an immersive environment through the use of AI.

We have used various AI models to create a completely free-to-use, self-hosted AI pipeline that lets users generate seamless 360 degree images, using only their voice input.
