# <p align="center"> 🌍 Vitrual Globetrotter 🌍 </p>

## ❓ What is Virtual Globetrotter?

**Virtual Globetrotter** is a team project between Atvars Apinis, Isabelle Desle, and Viola Nguyen that provides children with certain limitations the opportunity to explore the world in an immersive environment through the use of AI.

We have used various AI models to create a completely free-to-use, self-hosted AI pipeline that lets users generate seamless 360 degree images, using only their voice input.

## 🧠 AI Pipeline

### 1. [Google Gemma 2-2b-it](https://huggingface.co/google/gemma-2-2b)

Text-To-Text model used for enhancing the user's prompt.

### 2. [CyberRealistic](https://civitai.com/models/15003/cyberrealistic)

Finetuned Stable Diffusion Text-To-Image model typically used for generating portraits, but we adjusted the negative prompt to generate landscapes.

### 3. [Absolute Reality](https://civitai.com/models/81458?modelVersionId=134084)

Another finetuned Stable Diffusion model. This one, however, is an Image-To-Image inpainting model, which we used for generating a seamless 360 degree image from the one generated by CyberRealistic.

### 4. [Real ESRGAN](https://github.com/xinntao/Real-ESRGAN)

Used for image upscaling.

## 🗄️ Elasticsearch (Database)

For this project, our choice of database was **Elasticsearch**, both because it provided full-text search, and because we were already quite familiar with it.

For each image, the following information is stored: 
- Image path: The file path of the generated image is stored in Elastic Search, enabling efficient retrieval 
and reuse of existing images.
- Enhanced prompt: The prompt used to generate the image with the AI models is stored, providing context 
and facilitating future image retrieval based on similar inputs. 
- Title: A title is assigned to each image, which is used as the filename, allowing for organized storage and 
retrieval. 
- Continent: The continent associated with each image is stored, enabling filtering and retrieval of images 
based on geographical location.

The continent and voice input are used to search in the metadata and to show a relevant image.
To show the image, the score must be at least 8 and the image with the highest score is selected.  
 
If no matching image is found, a new image is generated. The resulting image is stored, and its metadata, including 
the folder path, prompt, title, and continent, is added to the database.
